# Architecture Decision Records

Architecture Decision Records (ADRs) capture significant, durable technical decisions.

Create an ADR when a decision has meaningful alternatives and long-lived consequences. Record the context, decision, status, and consequences. Do not create ADRs for routine implementation details or provisional ideas that have not been accepted.

The accepted decisions are [ADR 0001](0001-use-angular-and-nestjs-for-the-initial-application.md) for the initial application shape and [ADR 0002](0002-use-postgresql-and-drizzle-for-project-persistence.md) for project persistence.
