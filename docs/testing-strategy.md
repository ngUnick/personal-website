# Testing Strategy

Testing will follow the application as it is introduced. Each vertical slice should have tests proportionate to its risk and behavior, with a preference for fast feedback at the smallest useful scope.

The final mix of unit, integration, end-to-end, accessibility, and performance checks will be established with the application architecture and recorded when concrete tooling and runtime boundaries exist.

At this foundation stage, repository hygiene checks are the relevant validation: review the tracked diff, verify ignore boundaries, and confirm no dependencies or application code were introduced.
